# 高度 8192 的三次域零点证书与六个更小的二进斜率

设 $K=\mathbb Q(\alpha)$，$\alpha^3-\alpha-1=0$，$L(s)=\zeta_K(s)/\zeta(s)$。在整个临界带的 $0<\Im s\le8192$ 内，$L$ 恰有 **20185 个零点，都是中心线上的单零点**。较高度 1024 的表新增 18340 个。下表按重数统计正高度。首个开区间为 $(327/64,328/64)$，末个为 $(524282/64,524283/64)$。新旧表在 $0<t\le1024$ 的 1845 个区间逐行相同。[全部 20185 个区间](zeros23-8192.csv) · [两种高度的复算程序](verify_zeros23_1024.py)

| 高度上限 | 1024 | 2048 | 4096 | 8192 |
| --- | ---: | ---: | ---: | ---: |
| 正高度零点数 | 1845 | 4143 | 9188 | 20185 |

## 误差如何随高度改变

沿用前稿的旋转 Mellin 积分 $F(s)=e^{-i\alpha_0(s-1/2)}\Lambda(s)$，其中 $\Lambda(s)=(\sqrt{23}/(2\pi))^s\Gamma(s)L(s)$。为使顶边的指数衰减仍为 $e^{-64}$，将 $\alpha_0$ 取为 $\pi/2-1/128$。其他参数如下。[求积、插值与绕数公式的证明](cubic23-height-1024.md)

| 参数 | 高度 8192 的值 |
| --- | ---: |
| 旋转积分线两侧的半带宽 $d$ | $1/256$ |
| 梯形步长 $h$ | $1/8192$ |
| 截断 $\lvert j\rvert h\le 12$ 的最大指标 | $98304$ |
| 单位圆盘函数模上界 $B$ | $2^{44}$ |
| 中心线纵坐标步长 | $1/64$ |
| 顶边分段数、实插值次数 | $384,\ 40$ |
| 球算术精度 | 288 比特 |

程序先核对 $\cos(\alpha_0+d)/(\sqrt{23}/(2\pi))>d$ 以及 $4/((1-e^{-d})^2d^3)<B$。在 $|t|\le T=8192$ 上，Poisson 非零频移以及舍去 $|j|h>12$ 的尾项分别有界于

$$
 \frac{2B e^{-d(2\pi/h-T)}}{1-e^{-2\pi d/h}}<1.330\cdot10^{-60},
 \qquad
 \frac{8(de^{12}+1)e^{-de^{12}}}{d^4}<1.709\cdot10^{-263}.
$$

每次求值均将两项向外计入。旋转后的 $\eta$ 积分经一次卷积给出 $0\le t\le8192$ 的 524289 个严格符号。按 $[-1,2]+i[0,T]$ 的辐角原理另外计算绕数。顶边每一段有一个实或虚坐标保持定号，扣除误差的最小坐标余量大于 $1.188\cdot10^{-27}$。绕数在 $20185\pm5\cdot10^{-32}$ 内，与 20185 次严格变号相符。另取 $\alpha_0'=\pi/2-1/144$、$h'=1/9216$、$d'=1/288$、$B'=2^{45}$ 作交叉核对。在 $t=4096,6144,8192$ 和 $\sigma=1/2,5/4,2$ 构成的九个点，换回相同旋转后，两套求值区间逐点相交。底边的完备函数为正，左右竖边由 Euler 积和函数方程排除零点。故所有变号区间各含一个单零点，全带再无遗漏。[旋转 Mellin 法的出处](https://arxiv.org/abs/math/0507502) · [FLINT 的模函数球算术](https://flintlib.org/doc/acb_modular/index.html)

从仓库根目录运行 `python -B ERH/verify_zeros23_1024.py --height 8192` 可重得计数及余量，附加 `--csv` 会输出完整表格。CSV 采用 LF 行尾时，其 SHA-256 为 `1d5713fcddf52372860cb0ed2ffaa0da56dc7b008362f94ea723e36f961f1f95`。两次高度的低区间、斜率以及下面的素数和常数可由 `python -B ERH/gaussian23_bounds.py` 核对。两个程序都使用 `python-flint==0.9.0`。[常数与两份端点表复核](gaussian23_bounds.py)

## 已经保证的全尺度单侧下界

对任一已知上界 $\Re\rho\le b$（$1/2<b\le1$），最小斜率满足

$$
 \lambda_{23}\le\frac{2b-1}{8192^2-b^2+1/4}.
$$

这是因为可能对上确界有正贡献的零点均有 $|\Im\rho|>8192$。代入不同的全高度输入得到下表。[最小斜率与完全分裂素数单侧下界的等价定理](cubic23-gaussian-threshold.md)

| 全高度输入 | $\lambda_{23}$ 的严格上界 |
| --- | ---: |
| 临界带 $b=1$ | $1.491\cdot10^{-8}$ |
| Cureton–Thorner 的 $b=31/32$ | $1.397\cdot10^{-8}$ |
| 采用 Liu 混合矩预印本的 $b=0.8733326374459052$ | $1.113\cdot10^{-8}$ |

第二行已经小于 $2^{-26}$。因此相对于高度 1024 的已证范围，对六个更小的斜率 $\lambda=2^{-21},\ldots,2^{-26}$，每个充分大的整数尺度都满足单侧下界，容差指数 $\varepsilon>0$ 可任取。第三行另行采用预印本定理 7.33。[Cureton–Thorner 定理及 Lean 工程](https://github.com/AxiomMath/DedekindZetaZeroFree) · [Liu 的定理 7.33](https://hexagonmath.org/pdf/2611.00741v1)

还有一个带绝对常数的版本。写 $u=\log Y\ge30$，对每个 $v\ge\max(1,(u+99)/(8192^2-1))$ 都有

$$
 \left|P_v(u)-e^{u+v/2}/6\right|<22e^{u/2+v/8}.
$$

前稿把 $L$ 的所有高零点归一化后用 $5(4+T^2)e^{-99/2-v/8}$ 控制。此处换入 $T=8192$ 后，该项与低零点界 $145e^{-25/2}$、常数项 $e^{-15}$、左线余项 $30e^{-30}$ 的和仍小于 $0.001$，其余常数可原样使用。故仅用临界带及 Dirichlet GRH，固定方差 $v=1$ 的对数尺度已覆盖 $30\le u\le67108764$。要使斜率继续趋零，需要推过伴篇中一半的密度门槛，或以新的算术估计控制偶数平方自由理想的类差。[全尺度估计的推导](cubic23-gaussian-threshold.md) · [三阶特征的均方与密度](cubic23-class-character-mean-square.md) · [平方自由理想的剩余区间](cubic23-parity-window.md)
