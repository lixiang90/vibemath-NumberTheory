# 一张素数表中的和与差

## 两个问题

强哥德巴赫猜想考察每个大于 $2$ 的偶数能否写成两个素数之和，允许两个素数相同。孪生素数猜想考察是否有无穷多对相差 $2$ 的素数。下面在一个有限范围里展示两种配对方法。

## 固定偶数的素数表示

取 $n=26$，枚举所有满足 $p\leq n/2$ 的素数 $p$，逐一检查 $n-p$ 是否为素数。条件 $p\leq n-p$ 使每个无序表示恰好出现一次。

| $p$ | $26-p$ | 两者都是素数 |
| ---: | ---: | --- |
| 2 | 24 | 否 |
| 3 | 23 | 是 |
| 5 | 21 | 否 |
| 7 | 19 | 是 |
| 11 | 15 | 否 |
| 13 | 13 | 是 |

因此 $26$ 有三种无序素数表示，即 $3+23$、$7+19$ 和 $13+13$。

## 固定间距的素数对

仍取上界 $26$，这次枚举 $p+2\leq26$ 的素数 $p$，检查 $p+2$ 是否也是素数。满足条件的素数对恰为

$$
(3,5),\quad(5,7),\quad(11,13),\quad(17,19).
$$

上面的枚举给出了所选范围内的完整结果。要回答两个猜想，还需分别处理全体大于 $2$ 的偶数和无穷多对素数。
